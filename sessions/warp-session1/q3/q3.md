Question 3: ConfigMap and Secret Integration

Part A - Create Resources:
1. Create a ConfigMap named app-config with:
◦  Key APP_ENV with value production
◦  Key LOG_LEVEL with value info
◦  Key app.properties with value server.port=8080\nserver.host=0.0.0.0
2. Create a Secret named app-secret with:
◦  Key DB_USER with value admin

Part B - Create Pod:

◦  Inject DB_USER and DB_PASSWORD from the Secret as environment variables
◦  Mount the app.properties file from the ConfigMap to /config/app.properties inside the container

Please provide:
1. Commands (imperative) or YAML to create the ConfigMap
2. Commands (imperative) or YAML to create the Secret
3. YAML manifest for the Pod
4. A command to verify all environment variables are set correctly in the pod
5. A command to verify the app.properties file exists and has the correct content
