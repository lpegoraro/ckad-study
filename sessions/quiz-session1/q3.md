# Q3 — Deployment + ClusterIP Service

Goal
- Create a `Deployment` named `echo-deploy` (2 replicas) running `hashicorp/http-echo:0.2.3` that responds with `hello`.
- Create a `Service` named `echo-svc` (ClusterIP) that exposes the Deployment on port `8080`.

Constraints
- Pods must be labeled `app=echo` and the Service must select that label.
- Deployment containers should set the args to `-text=hello` and expose containerPort `5678`.
- Use only manifest files under `sessions/quiz-session1/`.

Time limit
- 12 minutes

Success criteria (exact kubectl checks)
- Deployment replicas:
  kubectl get deploy echo-deploy -o jsonpath='{.spec.replicas}'

- Deployment image:
  kubectl get deploy echo-deploy -o jsonpath='{.spec.template.spec.containers[0].image}'

- Service type and port:
  kubectl get svc echo-svc -o jsonpath='{.spec.type}'
  kubectl get svc echo-svc -o jsonpath='{.spec.ports[0].port}'

Notes
- You may use `kubectl --dry-run=client -o yaml` to generate starting manifests; save and edit them under `sessions/quiz-session1/` before applying.
- If using a non-default namespace, include `-n <namespace>` in verification commands.

When ready, apply the manifests from this folder and paste the outputs of the verification commands above for grading.
