Question 5: Services and Network Policies

You need to set up networking for a microservices application.

Part A - Create Services:
1. Create a Deployment named backend with:
◦  Image: nginx:alpine
◦  Replicas: 2
◦  Labels: app=backend, tier=api
◦  Container listens on port 80
2. Create a ClusterIP Service named backend-svc that:
◦  Exposes the backend deployment on port 8080
◦  Targets container port 80
◦  Uses the appropriate selector
3. Create a Deployment named frontend with:
◦  Image: nginx:alpine
◦  Replicas: 1
◦  Labels: app=frontend, tier=web
4. Create a NodePort Service named frontend-svc that:
◦  Exposes the frontend deployment on port 80
◦  Uses NodePort 30080
◦  Uses the appropriate selector

Part B - Testing:
5. Test connectivity from a frontend pod to the backend-svc service using curl
6. Verify the NodePort service is accessible

Please provide:
1. Commands or YAML to create both deployments
2. Commands or YAML to create both services
3. Command to test connectivity from frontend to backend service
4. Command to verify the NodePort service endpoint
5. Command to list all services and show their types and endpoints



CKAD Tip: Know the imperative commands for creating services - they're much faster than writing YAML! Use kubectl create service and kubectl expose.
