# Mock quizzes for CKAD practice

Place your mock quizzes in this folder. The agent will read and use these files for grading examples.

Format for a single quiz file (markdown):

- Metadata header with `id` and `topic`.
- Questions in numbered list. For grading, include an `answer:` block below each question with expected key points.

Example files:
- `mock-quiz-1.md` — simple sample quiz.
